# Developer Profile Website

A static developer profile website built using the MERN stack.

## Project Purpose

This project is a simple developer portfolio/profile page that displays:

- Personal introduction
- Technical skills
- Projects
- Contact links

## Technology Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Current Phase

Phase 1: Planning and project structure.

## Planned Features

- Responsive developer profile page
- Skills section
- Projects section
- Contact links section
- Simple backend API
- Optional MongoDB database integration
- Deployment
