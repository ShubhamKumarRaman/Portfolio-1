# API Plan

These are the planned API endpoints for the Developer Profile Website.

## Profile Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/profile | Get developer profile details |

## Skills Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/skills | Get all skills |

## Projects Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/projects | Get all projects |

## Contact Links Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/contact-links | Get all contact links |
